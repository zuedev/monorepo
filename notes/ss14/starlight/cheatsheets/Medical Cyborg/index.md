# Medical Cyborg Cheatsheet

## Loadouts

### Default

| Module | Setup |
|-|-|
| Basic Medical | Fill the beaker with Tricordrazine for quickly healing non-critical injuries. |
| Chemistry | Fill the beakers with Bicaridine and Dermaline for more advanced healing options. |
| Advanced Medical | Hypospray should have Epinephrine. Fill the beakers with Bicaridine and Dermaline as backup reserves for filling the menders. Replace Chemistry module beakers with Dylovene and Hyronalin. |

## Chemistry

Each recipe fills a 60u beaker. Set the dispenser to **10** unless a step says otherwise. Follow the steps in order.

### 🩸 Bicaridine (brute)

**Overdose:** 15u
**Healing:** 0.5 Blunt / 0.5 Slash / 0.5 Piercing per tick (1.5 total). Works in crit.

1. Oxygen ×1 (10u)
2. Carbon ×1 (10u)
3. Sugar ×1 (10u) → beaker reads **30 Inaprovaline**
4. Carbon ×3 (30u) → beaker reads **60 Bicaridine**

### 🔥 Dermaline (burn)

**Overdose:** 10u (asphyx, cold, jitter)
**Healing:** 1.5 Heat / 1.5 Shock / 1.5 Cold per tick. Does NOT heal Caustic. Works in crit.

1. Silicon ×1 (10u)
2. Carbon ×1 (10u) → beaker reads **20 Kelotane**
3. Oxygen ×2 (20u)
4. Phosphorus ×2 (20u) → beaker reads **60 Dermaline**

### 🌈 Tricordrazine (cheap all-rounder)

**Overdose:** no hard OD. >20u slows 25%, >40u poisons 1/tick and stops healing.
**Healing:** 0.75 total per tick, split across Brute / Burn / Poison. **Alive only — useless in crit.**

1. Oxygen ×1 (10u)
2. Carbon ×1 (10u)
3. Sugar ×1 (10u) → beaker reads **30 Inaprovaline**
4. Silicon ×1 (10u)
5. Nitrogen ×1 (10u)
6. Potassium ×1 (10u) → beaker reads **60 Tricordrazine**

### ☠️ Dylovene (toxin)

**Overdose:** 15u drunk; 20u blunt +2/tick, jitter, nausea
**Healing:** 1 Poison per tick. Works in crit. Does NOT touch Caustic or Radiation.

1. Silicon ×2 (20u)
2. Nitrogen ×2 (20u)
3. Potassium ×2 (20u) → beaker reads **60 Dylovene**

### ☢️ Hyronalin (radiation)

**Overdose:** 30u (Heat +2/tick, jitter)
**Healing:** 1 Radiation per tick. Works in crit. 2% chance per tick to make them vomit; warn the patient.

1. Silicon ×1 (10u)
2. Nitrogen ×1 (10u)
3. Potassium ×1 (10u) → beaker reads **30 Dylovene**
4. Radium ×3 (30u) → beaker reads **60 Hyronalin**
