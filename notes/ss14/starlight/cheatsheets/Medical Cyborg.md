# Medical Cyborg Cheatsheet

## Chemistry

Each recipe fills a 60u beaker. Set the dispenser to **10** unless a step says otherwise. Follow the steps in order.

### 🩸 Bicaridine (brute)

**Overdose:** 15u
**Healing:** 0.5 Blunt / 0.5 Slash / 0.5 Piercing per tick (1.5 total). Works in crit.

1. Oxygen ×1 (10u)
2. Carbon ×1 (10u)
3. Sugar ×1 (10u) → beaker reads **30 Inaprovaline**
4. Carbon ×3 (30u) → beaker reads **60 Bicaridine**

### 🔥 Dermaline (burn)

**Overdose:** 10u (asphyx, cold, jitter)
**Healing:** 1.5 Heat / 1.5 Shock / 1.5 Cold per tick. Does NOT heal Caustic. Works in crit.

1. Silicon ×1 (10u)
2. Carbon ×1 (10u) → beaker reads **20 Kelotane**
3. Oxygen ×2 (20u)
4. Phosphorus ×2 (20u) → beaker reads **60 Dermaline**

### 🌈 Tricordrazine (cheap all-rounder)

**Overdose:** no hard OD. >20u slows 25%, >40u poisons 1/tick and stops healing.
**Healing:** 0.75 total per tick, split across Brute / Burn / Poison. **Alive only — useless in crit.**

1. Oxygen ×1 (10u)
2. Carbon ×1 (10u)
3. Sugar ×1 (10u) → beaker reads **30 Inaprovaline**
4. Silicon ×1 (10u)
5. Nitrogen ×1 (10u)
6. Potassium ×1 (10u) → beaker reads **60 Tricordrazine**

Inaprovaline first, then Dylovene. Reversed order makes Ethylredoxrazine instead.

## ⚠️ Don'ts

- **Never mix Bicaridine with Bruizine, Lacerinol, or Puncturase.** Any pair makes Razorium. Bic gets its own beaker.
- **Dermaline ODs at 10u.** Pill it in 5u doses, never bottle-dose.
- **No water in the beaker before Potassium.** Rinse if you reused it for Saline.
